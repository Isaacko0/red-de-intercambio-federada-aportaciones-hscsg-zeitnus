---\nname: brief-detector-recommender\ndescription: Detecta gaps en la documentación, recomienda briefs prioritarios, proyecta necesidades futuras y extrapola patrones; invocable por el orquestador.\nversion: 0.1.0\nauthor: Isaac Ko (Isaacko0), Hermes Agent\nlicense: LPF-1.0\n---\n\n# Brief Detector & Recommender Skill\n\nSkill que detecta gaps en la documentación, recomienda briefs prioritarios, proyecta necesidades futuras y extrapola patrones de asimilación. Diseñada para ser invocada por el orquestador como parte del ciclo de mejora continua.\n\n## Cuándo usar\n- Tras cada asimilación de repo/proyecto (trigger automático vía orquestador)\n- Cuando el orquestador detecta que `BRIEFS_INDEX.md` está desactualizado\n- Usuario pregunta \"¿qué briefs faltan?\" o \"¿qué brief crear ahora?\"\n- Ciclo semanal de mantenimiento de documentación\n- Antes de planificar la próxima asimilación (input para decisión)\n\n## Prerrequisitos\n- Repo `red-de-intercambio-federada-aportaciones-hscsg-zeitnus` clonado en `main`\n- `docs/BRIEFS_INDEX.md` existente y parseable\n- `docs/BRIEF_EXHAUSTIVO_HSCSG_COSATECA_OS.md` como referencia fundacional\n- `docs/fuentes_indice.json` con fuentes asimiladas\n- Node 24 + Python 3.11+\n\n## Cómo ejecutar\n\n```bash\n# Invocación desde el orquestador (recomendada)\nnode scripts/brief-detector-recommender.js detect\nnode scripts/brief-detector-recommender.js recommend\nnode scripts/brief-detector-recommender.js project\nnode scripts/brief-detector-recommender.js extrapolate\nnode scripts/brief-detector-recommender.js full-cycle\n\n# O directamente:\n# cd <repo-destino> && node scripts/brief-detector-recommender.js full-cycle\n```\n\n## Referencia rápida\n\n| Comando | Acción |\n|---------|--------|\n| `detect` | Escanea `BRIEFS_INDEX.md` + `fuentes_indice.json` + repo → detecta gaps, duplicados, desactualizados |\n| `recommend` | Basado en gaps + prioridad estratégica → lista briefs recomendados con prioridad P0/P1/P2 |\n| `project` | Proyecta necesidades a 30/60/90 días basado en roadmap + gaps + tendencias |\n| `extrapolate` | Extrapola patrones de asimilación → predice próximos repos, skills, briefs |\n| `full-cycle` | Ejecuta detect → recommend → project → extrapolate → genera reporte + actualiza `BRIEFS_INDEX.md` |\n\n## Arquitectura\n\n### Fuentes de entrada (parseadas automáticamente)\n\n1. `docs/BRIEFS_INDEX.md` — Índice actual (tablas markdown parseadas)\n2. `docs/fuentes_indice.json` — Fuentes asimiladas + estado\n3. `docs/BRIEF_EXHAUSTIVO_HSCSG_COSATECA_OS.md` — Brief fundacional (gaps vs visión)\n4. `scripts/orchestrator-next-steps.js` — Workstreams activos + tasks pendientes\n5. `cmd/` + `internal/` + `pos/` — Código actual (módulos implementados vs gaps)\n6. `skills/` — Skills desplegadas vs pendientes\n7. Historial git — Últimas asimilaciones (patrón temporal)\n\n### Algoritmos core\n\n#### 1. Detección de Gaps (Detect)\n- Fuentes en `fuentes_indice.json` con estado Pendiente → gap BI-XXX\n- Briefs en `BRIEFS_INDEX.md` con estado P0 Pendiente → gap SM-XXX\n- Módulos en `internal/`/`cmd/`/`pos/` vs briefs → módulos sin spec\n- Skills en `skills/` vs briefs → skills sin documentación\n- Vasos comunicantes en el orquestador vs specs → vasos sin spec\n- Proyectos en `fuentes_indice.json` sin backup/integration → gap BI-XXX\n- Términos en \"Madurez por Término\" con 🔴/🟡 sin brief asociado → gap\n- Duplicados: mismo concepto en múltiples briefs sin consolidar\n\n#### 2. Motor de Recomendación (Recommend)\n`Score = (Valor_Estratégico × 0.4) + (Factor_Desbloqueo × 0.3) + (Esfuerzo_Inverso × 0.2) + (Conteo_Dependencias × 0.1)`\n\n#### 3. Proyección (Project)\n- Horizonte 30d: gaps P0 + workstreams activos del orquestador\n- Horizonte 60d: gaps P1 + términos 🟡 en \"Madurez por Término\" + skills pendientes\n- Horizonte 90d: visión fundacional (fases) + tendencias de asimilación (~1 repo / 2 semanas)\n\n#### 4. Extrapolación (Extrapolate)\nPatrones detectados:\n- Frecuencia de asimilación: 1 repo / 2 semanas (historial git)\n- Tipos de repo: identidad > gobernanza > economía > infra > IA > social\n- Briefs por repo: 2 (backup + integration) + 0-3 specs + 0-1 skill\n- Predicción: próximos 3 repos probables, 6-8 briefs, 1-2 skills\n\n---\n\n## Integración con el Orquestador\n\n### Invocación desde el orquestador\n```javascript\n// En scripts/orchestrator-next-steps.js\naction('brief-detect') → node scripts/brief-detector-recommender.js detect\naction('brief-recommend') → node scripts/brief-detector-recommender.js recommend\naction('brief-project') → node scripts/brief-detector-recommender.js project\naction('brief-extrapolate') → node scripts/brief-detector-recommender.js extrapolate\naction('brief-full-cycle') → node scripts/brief-detector-recommender.js full-cycle\n```\n\n### Actualización del estado del orquestador\n```json\n{\n  \"briefDetector\": {\n    \"lastRun\": \"YYYY-MM-DDTHH:mm:ssZ\",\n    \"gapsDetected\": N,\n    \"recommendationsGenerated\": N,\n    \"projection30d\": N,\n    \"projection60d\": N,\n    \"projection90d\": N,\n    \"extrapolationNextRepos\": [\"Repo1\", \"Repo2\", \"Repo3\"],\n    \"nextBriefsPredicted\": N,\n    \"lastReportPath\": \"docs/brief-detection-report.json\"\n  }\n}\n```\n\n---\n\n## Verificación\n\n```bash\n# Test rápido\nnode scripts/brief-detector-recommender.js detect\nnode scripts/brief-detector-recommender.js recommend\nnode scripts/brief-detector-recommender.js full-cycle\n\n# Verificar outputs\ncat docs/brief-detection-report.json\ncat docs/brief-recommendations.md\ncat docs/brief-projection-30-60-90.md\ncat docs/brief-extrapolation.md\n\n# Verificar BRIEFS_INDEX.md actualizado\ngrep -c "BF-" docs/BRIEFS_INDEX.md\n```\n\n---\n*Adaptado de `Marca-Blanca-Zeitnus-Firma-Operaciones-Ecotomica-Networking-Recreativo` → `red-de-intercambio-federada-aportaciones-hscsg-zeitnus`.*
