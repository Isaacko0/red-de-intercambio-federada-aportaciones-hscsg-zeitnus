Ningún documento existe en aislamiento. Cada claim tiene su vaso comunicante hacia evidencia, código, test y decisión.\n\n## Metodología Unificada: 5 Fases Obligatorias (En Orden)\n\n### FASE 0 — Respaldo PRIMERO (Siempre)\n```bash\ncp -r <repo-destino> <repo-destino>_BACKUP_$(date +%Y%m%d_%H%M%S)\n```\n\n### FASE 1 — Clonar + Documentar Fuente (Asimilación) O Leer 8 Docs Base (Ciencia)\n**Asimilación:** `git clone --depth 1 https://github.com/<owner>/<repo>.git repo_<short>` y verificar archivos.\n**Ciencia:** leer los 8 documentos base de investigación si existen en `docs/research_output/`.\n\n### FASE 2 — Documentar (Backup + Integración) O Diseñar (EBD + Vasos Comunicantes)\n**Asimilación:** crear `docs/<repo>_backup.md` + `docs/<repo>_integration.md` (triple perspectiva Usuario/LLM/HSCSG).\n**Ciencia:** aplicar EBD + vasos comunicantes:\n```\nEVIDENCIA → ANÁLISIS REQUISITOS → DISEÑO SOLUCIÓN → PROTOTIPADO MVP → VALIDACIÓN CUANTITATIVA → ITERACIÓN → DOCUMENTACIÓN TRAZABLE\n```\n**Decisiones EBD (D1-D8)** — plantilla obligatoria en todo documento:\n| D# | Decisión | Evidencia Primaria | Módulo/Test Afectado |\n\n**Vasos Comunicantes Obligatorios (citas internas):**\n- Decisión EBD: `[EBD-D#]`\n- Validación: `[DV-#]`\n- Test KPI: `[KPI-Nombre]`\n- Código: `[internal/<modulo>/archivo.go:L##]`\n- Dato bruto: `[data/benchmark/archivo.csv]`\n- Riesgo: `[R#]`\n\n### FASE 3 — Módulo Real / Prototipo Mínimo + Tests KPI\n**Asimilación:** tipos `internal/<modulo>/types.go`, lógica `internal/<modulo>/service.go`, registro en orchestrador, tests en `internal/<modulo>/service_test.go`.\n**Ciencia / ADS nativos:** módulos + tests KPI cuantificables (routing, latencia, disponibilidad, recuperación).\n\n### FASE 4 — Verificación Obligatoria ANTES de Entregar\n```bash\ncd <repo-destino>\ngo build ./...          # 0 errores\ngo test ./...           # 100% pass\n# Para papers: reproducibilidad\n./scripts/benchmark/run_benchmark.sh  # ejecutar sin errores\n```\n\n### FASE 5 — Commit, Push, Tag, Zenodo, Anuncio\n```bash\ngit add .\ngit commit -m \"feat: <Modulo/Paper> (<repo>) + docs + tests\n\n- EBD: [EBD-D1, EBD-D4]\n- DV: [DV-01, DV-02]\n- KPI: [KPI-Availability, KPI-RoutingAccuracy]\n- Ref: #issue-number\n\nEvidencia: docs/research_output/ + tests + benchmarks\"\ngit push origin main\ngit tag docs/v1.0-<nombre>\n```\n\n## Principio de Vasos Comunicantes Totales (Cross-Repo)\nCada elemento tiene 4 conexiones trazables: Evidencia ↔ Decisión EBD/Validación ↔ Módulo Código ↔ Test KPI ↔ Paper/Doc.\n\n## Checklist Pre-Entrega\n- [ ] Backup creado (ruta + size)\n- [ ] Fuente clonado + verificado (>0 archivos)\n- [ ] `docs/<repo>_backup.md` + `<repo>_integration.md` creados\n- [ ] Módulo completo: tipos + lógica + registro + tests\n- [ ] Isomorfismo Leyes I/II/III + CaaS documentado\n- [ ] `go build ./...` → 0 errores\n- [ ] `go test ./...` → 100% pass\n- [ ] Commit + push + tag trazable (EBD, DV, KPI, refs)\n\n---\n*Adaptado de `Marca-Blanca-Zeitnus-Firma-Operaciones-Ecotomica-Networking-Recreativo` → `red-de-intercambio-federada-aportaciones-hscsg-zeitnus`.*
